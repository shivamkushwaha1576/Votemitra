# 🗳️ Election Education Mitra

## 📌 Project Description
Election Education Mitra ek interactive web application hai jo users ko election process ke baare me educate karta hai. 
Isme voter registration se lekar vote counting tak sab kuch simple aur interactive way me explain kiya gaya hai.

---

## 🎯 Objective
Is project ka goal hai logon ko elections ke baare me awareness dena aur unhe informed voter banana.

---

## 🚀 Features
- 📚 Topic-based learning (Sidebar navigation)
- 🔍 Search topics functionality
- 🗳️ Voter Registration guide
- 🧾 Voting methods explanation
- 📅 Election timeline
- ⚙️ Voting process step-by-step
- 📊 Vote counting explanation
- 🛡️ Voter rights awareness
- 🎨 Clean UI with interactive design

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
